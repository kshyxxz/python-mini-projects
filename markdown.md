# Markdown Basics

## Headings

Use `#` symbols for headings:

```markdown
# H1
## H2
### H3
```

## Bold and Italic

```markdown
**bold text**
*italic text*
```

## Lists

### Unordered list

```markdown
- Item 1
- Item 2
	- Nested item
```

### Ordered list

```markdown
1. First
2. Second
3. Third
```

## Links

```markdown
[OpenAI](https://openai.com)
```

## Images

```markdown
![Alt text](image.jpg)
```

## Code

Inline code uses backticks: `code`

```markdown
```python
print("Hello, world!")
```
```

## Blockquotes

```markdown
> This is a quote.
```

## Horizontal Rule

```markdown
---
```

## Tables

```markdown
| Name  | Age |
|-------|-----|
| Alice | 25  |
| Bob   | 30  |
```
